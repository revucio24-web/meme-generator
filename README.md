# 😂 Meme Generator Pro

Ein kostenloser, lokaler Meme-Generator mit Text, Effekten und Download-Optionen.
Alles läuft im Browser – keine Daten werden gesendet.

## Features

- ✅ Eigene Bilder hochladen (Drag & Drop)
- ✅ 8 Template-Platzhalter
- ✅ Text oben/unten oder mittig
- ✅ 9 Schriftarten (inkl. Google Fonts)
- ✅ Farben, Outline, Schatten anpassbar
- ✅ 4 Stil-Presets (Klassisch, Modern, Comic, Minimal)
- ✅ 6 Bildfilter (Graustufen, Sepia, Invertieren, Helligkeit, Kontrast)
- ✅ Vignette und Rahmen
- ✅ Canvas-Größen (500x500, 800x600, 600x800, 1080x1080)
- ✅ Download als PNG, JPG oder WebP
- ✅ 100% kostenlos, keine Anmeldung

## Verwendung

1. Öffne `index.html` in deinem Browser
2. Lade ein Bild hoch oder wähle ein Template
3. Gib Text ein (oben/unten)
4. Passe Stil und Effekte an
5. Lade das Meme herunter

## Technik

- HTML/CSS/JavaScript
- Canvas API
- Google Fonts (kostenlos)
- Keine Backend-Abhängigkeiten
